# CampusLens

### Point. Understand. Fix.

CampusLens is an AI-powered campus issue reporting platform that helps students report real-world problems simply by showing them to a camera.

Instead of finding the correct department, writing a detailed complaint, and repeatedly following up, students can use CampusLens to capture an issue and turn it into a structured report.

## 🚀 The Problem

College campuses have many small problems that often take too long to report or resolve:

* Broken furniture
* Water leakage
* Overflowing garbage
* Blocked wheelchair ramps
* Damaged signs
* Infrastructure problems
* Unsafe-looking wiring
* Other maintenance issues

The biggest problem is not always finding the issue.

It is getting the issue from:

**"Someone noticed it" → "The right person knows about it" → "It gets fixed"**

CampusLens is designed to connect these steps.

---

## 💡 Our Solution

CampusLens uses a camera-first approach.

A student can simply capture a photo of a campus problem.

The system can then help:

1. Understand what is visible in the image
2. Identify the type of issue
3. Suggest its severity
4. Identify the relevant building or location
5. Check for possible duplicate reports
6. Create a structured maintenance report
7. Allow administrators to track the issue
8. Review a later photo after the repair

### One photo → One actionable report

---

## 📸 Student Dashboard

The student dashboard is designed to make reporting simple.

Students can:

* Capture or upload a photo
* Report a campus problem
* View the detected issue
* See location information
* Check possible duplicate reports
* Track report progress
* See whether the issue is resolved

The goal is to make reporting take seconds instead of several manual steps.

---

## 🏢 Building Admin Dashboard

The building admin dashboard is designed for people responsible for campus maintenance.

Administrators can:

* View reported issues
* Filter reports
* Review issue details
* Check priorities
* Update report status
* Manage ongoing problems
* Review repair evidence

This creates a visible connection between the student who reported a problem and the person responsible for resolving it.

---

## 🤖 AI Workflow

CampusLens is designed around an AI agent workflow rather than a simple chatbot.

```text
Photo
  ↓
AI understands the scene
  ↓
Issue identified
  ↓
Location / context detected
  ↓
Duplicate reports checked
  ↓
Report created
  ↓
Admin reviews and updates status
  ↓
Repair evidence submitted
  ↓
Issue can be verified and closed
```

The AI is intended to help the system **understand and act**, not just describe an image.

---

## ✅ Before & After Verification

One of the key ideas behind CampusLens is repair verification.

### Before

A student reports an issue with a photograph.

### After

A new photograph is submitted after the repair.

CampusLens can use the two states as evidence for the resolution process.

This helps move the system from:

**Complaint reporting**

to

**Issue → Action → Verification**

---

## 🔎 Duplicate Detection

The same campus problem may be reported by multiple students.

CampusLens is designed to detect possible duplicate reports before creating unnecessary new complaints.

For example:

> "This issue may already have been reported."

This can reduce repeated reports and help administrators focus on actual unresolved problems.

---

## 🔐 Privacy

CampusLens is designed with privacy in mind.

Potential privacy measures include:

* Redacting unnecessary personal information
* Blurring faces or license plates
* Limiting stored information
* Keeping sensitive data to a minimum

Privacy can be improved further through on-device AI processing in future versions.

## 🎬 Hackathon Demo

The main demonstration can be shown using a simple campus scenario.

### Example

A wheelchair ramp is blocked by bicycles.

The student points the camera at it and selects:

**"Report this."**

CampusLens analyzes the image and produces information such as:

* Issue: Accessibility obstruction
* Location: Building / area
* Severity: Medium
* Suggested department: Facilities
* Recommended action: Remove the obstruction

The report then appears in the admin dashboard.

After the bicycles are removed, an **after photo** can be submitted for review.

## 🛠️ Technology

CampusLens is a prototype built around:

* AI-based image understanding
* Camera / image upload
* Web-based dashboards
* Issue tracking
* Location information
* Duplicate detection
* Before/after verification

The prototype uses **Gemma 4** as the core AI concept for multimodal understanding.

## 📊 Project Vision

The long-term vision of CampusLens is to create a smarter campus operations system where physical problems can be reported and managed through a simple visual interface.

Instead of:

> Find the office → Explain the issue → Submit complaint → Follow up

the experience becomes:

> **Point → Understand → Report → Fix**
